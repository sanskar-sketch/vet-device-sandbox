ℹ️ How to Use

1. Select Device — click a device card above

2. Configure Connection — fill in IP/port/transport params

3. Connect — click ▶ Connect

4. Choose Action — stream or request (batch)

5. View Data — real-time data appears in the Data Stream tab

6. Check Schema — Output Schema tab documents every field

Mode: This fetcher uses the same driver architecture as individual device pages. Flip USE_REAL_DEVICE in js/driver-base.js to switch from simulation to real hardware.
